# Ideas

This directory preserves potentially valuable concepts without turning them into promised features.

## Idea lifecycle

```text
Captured → Exploring → Validated → Accepted → Scheduled → Shipped
                       ↘ Rejected
                       ↘ Parked
```

Definitions:

- **Captured:** Worth remembering; no research or commitment.
- **Exploring:** A user problem and smallest test are being defined.
- **Validated:** Evidence supports the problem or opportunity.
- **Accepted:** The team has explicitly chosen to pursue it.
- **Scheduled:** Assigned to a roadmap milestone or release.
- **Shipped:** Available in the product and documented in `current-product.md`.
- **Parked:** Intentionally deferred.
- **Rejected:** Not pursuing; reasoning is recorded.

## Logging an idea

Add a row to `idea-log.md`, then give material ideas their own file using `idea-template.md`.

An idea should answer:

- Whose problem is this?
- What happens today?
- What outcome would improve?
- What evidence supports it?
- What is the smallest useful test?
- What new privacy, safety, data, or infrastructure risk does it introduce?
- What would make us stop?

AI agents may organize, research, or critique captured ideas. They must not implement them until the idea is accepted or the user directly authorizes the work.
