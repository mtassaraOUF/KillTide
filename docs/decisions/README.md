# Decision Records

Decision records explain consequential choices so future collaborators and AI agents understand the reasoning, not just the result.

Create a record when a decision materially affects:

- Product scope
- Data storage
- Privacy
- Location handling
- Marine-data provenance
- Safety
- AI responsibilities
- Infrastructure or recurring cost

Use sequential names such as `0001-local-first-proof-of-concept.md`.

Do not rewrite old decisions to make history look cleaner. If a choice changes, add a new record that supersedes the previous one.
